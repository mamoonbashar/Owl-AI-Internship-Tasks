
# 🦉 Owl AI: Interactive Image Classifier

Owl AI is a modern, responsive web application that leverages **MediaPipe's Image Classification** to identify objects in real-time. Built as part of **Task 4**, this project demonstrates a seamless blend of sophisticated UI design and powerful Machine Learning.

## 🚀 Features

* **Real-Time AI Processing:** Instantly identifies objects with high accuracy.
* **Top-3 Predictions:** Shows the most likely identification along with two "runner-up" guesses.
* **Interactive Drag & Drop:** Users can drag images directly into the interface or browse their local files.
* **Glassmorphism UI:** A modern, sleek design with blurred backgrounds and smooth animations.
* **Mobile Responsive:** Fully optimized for desktops, tablets, and smartphones.

## 🛠️ Tech Stack

* **HTML5 & CSS3:** For structural semantic markup and advanced styling (Flexbox/Grid).
* **JavaScript (ES6+):** Core logic for file handling and UI interaction.
* **MediaPipe Tasks Vision:** Google's state-of-the-art ML library for image classification.
* **EfficientNet-Lite0:** A lightweight, high-performance classification model.

## 💻 Getting Started

### Prerequisites

You don't need to install any heavy software. Just a modern web browser and a local server (like VS Code's **Live Server** extension).

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/owl-ai.git

```


2. **Navigate to the project folder:**
```bash
cd owl-ai

```


3. **Launch with Live Server:**
Open `index.html` in VS Code, right-click, and select **"Open with Live Server"**.

---

## 📖 How to Use

1. Click the **"Upload Image Box"** area or drag an image file onto the screen.
2. Wait for your image to appear in the preview window.
3. Press the **"Upload Image"** button.
4. **Owl AI** will display the top guess prominently, with additional confidence scores listed below.
