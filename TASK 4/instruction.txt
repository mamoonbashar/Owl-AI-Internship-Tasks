    File Descriptions & Their Logic
1. index.html (The Skeleton)
What it does: Links all your CSS and JS files.

Key Logic: Contains the "Drop Zone" div, the "Scanner" container, and the navigation bar. 
You should put your "Bento Grid" section here.

Tip: Add type="module" to your script tags if you want to use modern JS features cleanly.

2. css/style.css (The Look)
What it does: Defines the Glassmorphism colors, the dark mode background, and the grid layout.

Key Logic: Sets the base "look and feel." It makes the page responsive (using @media queries) so it works on mobile.

3. css/animations.css (The "Wow" Factor)
What it does: Handles the "Scanning Line" movement, the glowing pulse on buttons, 
and any entry animations when the page loads.

Key Logic: Uses @keyframes to move the scanning bar up and down the image container.

4. js/main.js (General Interactions)
What it does: Handles site-wide tasks like the sticky navbar or "Smooth Scroll" to sections.

Key Logic: If you add a "News API" or a typewriter greeting, the code goes here.

5. js/upload.js (The Simulation Handler)
What it does: Watches for a file selection or "Drop" event.

Key Logic: It uses the FileReader API to convert the user's uploaded image into a "Data URL"
 so it shows up in the browser 
immediately. This is the file that "unlocks" the scanner once an image is ready.

6. js/scanner.js (The Mouse Logic)
What it does: Tracks the mouse position specifically over the image.

Key Logic: This file contains the mousemove listener. It calculates the offsetX and offsetY
 and updates the text inside the "Owl's Eye" box (Confidence level, object labels, etc.).
